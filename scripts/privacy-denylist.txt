# Privacy rules for public files in this repository.
#
# Read by crate/sigil/tests/privacy_check.rs, which runs with `cargo test`.
# The test walks every text file in the repository (skipping .git, target and
# node_modules) and fails if a line matches a rule below.
#
# Public docs should not depend on the environment they were written in.
# Use generic examples (`/home/me/...`, `~/backups`) and neutral wording such
# as "Debian-based Linux", "a second machine" or "maintainer decision".
#
# Keep this file generic. Project-specific terms are not listed here: put them
# in an untracked local file and point SIGIL_PRIVACY_DENY_EXTRA at it (same
# format). SIGIL_PRIVACY_SCAN_EXTRA (colon-separated files or folders) adds
# text outside the repository to the scan, such as a draft PR body or a wiki
# checkout.
#
# Format, one rule per line:
#   deny <term>          case-insensitive substring; whole word when the term
#                        starts or ends with a letter or digit
#   allow <text>         this exact text (case-sensitive) is exempt; the rest
#                        of the line is still scanned; an allowed text ending
#                        in "/" followed by ".." still fails
#   allow-file <path>    repo-relative path that is not scanned
# Built-in rule: a UUID-shaped id on a line that mentions "machine" fails.
#
# PDFs are scanned through `pdftotext` (poppler-utils). If it is missing the
# check fails and says so; SIGIL_PRIVACY_SKIP_PDF=1 skips PDFs with a warning.
# JPEG and PNG files are scanned in their metadata (EXIF, XMP, comments, text
# chunks, compressed zTXt/iTXt inflated first). Rebuild docs/WHITEPAPER.pdf with scripts/build-whitepaper-pdf.py
# whenever docs/WHITEPAPER.md changes.

# Real home folders. Use the placeholder `/home/me/` in examples.
deny /home/
deny /users/
allow /home/me/
allow /Users/me/
# Absolute paths of a build or scratch machine.
deny /workspace/

# This file names the patterns on purpose.
allow-file scripts/privacy-denylist.txt
